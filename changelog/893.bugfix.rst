|commands| :class:`ApplicationCommandInteraction.application_command` is now the parent slash command (instead of the invoked subcommand) when :meth:`~ext.commands.InvokableSlashCommand.after_invoke` is called for said slash command. Previously, :meth:`~ext.commands.InvokableSlashCommand.after_invoke` would be called twice with the subcommand, instead of once for the parent command and once for the subcommand.
